Replay Clipper 使用说明
=======================

Replay Clipper 用于保存最近几分钟的游戏画面，使用方式与游戏主机上的"保存最近的
游戏"类似：程序在后台持续录制所选的显示器，同时录制系统声音，也可以一并录制
麦克风。需要保留时选择时长（3、5、15、30 分钟或自定义）或按下对应的快捷键，
即可保存为片段，并可在程序内播放和裁剪。

2.0 版由程序自身完成录制，不再需要 OBS Studio。从 1.0 版升级的用户请参阅下文
"从 1.0 版升级"一节。

English documentation: README.txt。界面语言可在窗口右上角切换。


运行环境
--------
· Windows 10 或 11，64 位
· 用于存放回放缓存的磁盘空间，「录制设置」中会显示当前设置预计占用的空间
· 无需安装其他软件，录制组件和 ffmpeg 已包含在本文件夹中

录制使用显卡的视频编码器（NVIDIA、AMD 或 Intel）。没有可用的显卡编码器时改用
软件编码；软件编码会使游戏帧率明显下降，出现这种情况时「录制设置」中会给出提示。


首次使用
--------
1. 从开始菜单或桌面快捷方式启动 Replay Clipper。
   （如果拿到的是文件夹而不是安装程序，请将文件夹放在固定位置后运行 ReplayClipper.exe。）
2. 首次运行时会自动打开「录制设置」。确认要录制的显示器和其他各项设置
   （见下文"录制设置"一节），然后选择「开始录制」。
   如果未开始录制就关闭了对话框，首页会显示「尚未设置录制」，并提供
   「录制设置」按钮。
3. 此后程序在后台持续录制。首页显示录制状态（例如
   「后台录制中 · 保留最近 30 分钟」）和各个保存时长。


日常使用
--------
· 保存：在首页选择时长，或按下对应的快捷键，最近这段时间的画面即保存为片段。
  已录制的画面不足所选时长时，保存回放缓存中的全部内容。
  片段从回放缓存中直接截取，不重新编码。片段的起点落在录制内容中每两秒一处的
  分界点上，因此实际时长可能比所选时长多出最多两秒。片段越长，保存所需的时间
  越长。以下数据仅供参考，并非保证：在开发所用的电脑上（NVMe 固态硬盘、默认
  画质），保存 5 分钟约需 0.2 秒，保存 30 分钟约需 1 秒。
· 播放和裁剪：在「片段」中打开任意片段；选择「裁剪」，拖动时间轴两端的滑块，
  再选择「导出片段」。导出为无损方式（不重新编码）。
· 停止：在首页的录制状态旁选择「停止」。尚未保存的画面将被丢弃，回放缓存占用的
  磁盘空间随之释放。需要再次录制时，选择「开始录制」。
· 程序会记住录制是否开启：开始录制后，每次启动程序都会自动继续录制，直到选择
  「停止」。


保存时长与快捷键
----------------
首页以方块的形式列出保存时长，最多五个。选择方块与按下它的快捷键效果相同。
默认设置如下：

  3 分钟     Alt+F7
  5 分钟     Alt+F8
  15 分钟    Alt+F9
  30 分钟    Alt+F10

快捷键为全局快捷键：只要 Replay Clipper 在运行（包括没有窗口、只在后台运行时），
在游戏和其他程序中都可使用。通过快捷键或通知区域图标的菜单保存时，屏幕右上角
会显示一条小提示，保存完成时播放系统提示音。

修改时长和快捷键：在首页时长方块后面选择「编辑」，或在「录制设置」的
"保存时长与快捷键"一行选择「编辑…」。
· 时长：15 秒至回放时长之间。
· 快捷键：选择快捷键框后按下新的组合键。功能键可以单独使用，其他键需要包含
  Ctrl 或 Alt；不能使用 Win 键和系统保留的组合键（如 Alt+F4、Alt+Tab）。
  时长也可以不设置快捷键。
· 「添加」用于增加时长，最多五个；「恢复默认设置」恢复为上面列出的四个时长和
  快捷键。
· 选择「保存」后生效，在此之前不会有任何改动。

已被其他程序占用的快捷键无法保存，对话框中会标出「已被其他程序占用」。快捷键
之后变得不可用时，对应的方块显示「快捷键不可用」，此时仍可通过选择该方块保存。

回放时长短于某个方块的时长时，该方块保存回放缓存中的全部内容。


后台运行
--------
程序运行期间，任务栏的通知区域中会显示 Replay Clipper 的图标。录制和快捷键
不依赖窗口。

· 关闭窗口时，程序会询问是在后台继续运行还是退出。勾选「不再提醒」后，程序会
  记住这一选择，之后可在「录制设置」的「关闭窗口时」中更改。退出程序时，录制
  停止，尚未保存的画面将被丢弃，快捷键不再可用。
· 选择通知区域中的图标可打开窗口。右键单击图标可打开菜单，其中有
  「打开 Replay Clipper」、每个时长对应的保存命令（如「保存最近 3 分钟」）、
  「开始录制」或「停止录制」，以及「退出」。
· 程序运行期间再次启动 Replay Clipper，会打开它的窗口。
· 需要随 Windows 启动时，在「录制设置」中打开「开机时启动并在后台录制」。
  此后程序启动时只在通知区域显示图标，不打开窗口；之前开启了录制的，会自动
  继续录制。


录制设置
--------
在标题栏选择「录制设置」。

· 录制的显示器：连接两台及以上显示器时，按实际排布显示示意图，从中选择运行
  游戏的显示器；选择「识别」可在每台显示器上显示对应的编号。
· 分辨率：1080p、1440p 或显示器的原始分辨率，不提供高于显示器分辨率的选项。
  分辨率越高，文件越大，占用的磁盘空间越多。
· 帧率：60 帧/秒或 30 帧/秒。
· 回放时长：最多可以保存多久以前的画面。可选 15 分钟、30 分钟、1 小时、2 小时，
  或选择「自定义」并填写 1 至 720 分钟（12 小时）。回放缓存保存在磁盘上，
  对话框中会显示预计占用的磁盘空间，以及缓存所在磁盘的可用空间。
· 编码器：「自动」，或本机可用的某个编码器。
· 保存位置：片段保存文件夹。可直接填写路径，或选择「浏览…」选取文件夹。
  片段不能保存在程序自己的文件夹或缓存文件夹中。
· 缓存位置：回放缓存（保存片段时从中截取的循环录制）的存放位置，默认为程序的
  数据文件夹。选择其他位置时，程序会在该位置下自建一个名为
  "Replay Clipper buffer"的子文件夹存放缓存，对话框中会显示实际使用的文件夹。
  不能使用网络位置。可直接填写路径，或选择「浏览…」选取文件夹；「恢复默认」
  可改回默认位置。
· 录制麦克风：关闭时仅录制系统声音。
· 开机时启动并在后台录制。
· 关闭窗口时：「每次询问」「后台运行」或「退出程序」。

选择「保存」。录制开启时，部分改动会使录制重新开始；更改显示器、分辨率、帧率、
编码器或缓存位置时，回放缓存中已有的画面还会被清空。保存前对话框中会给出提示。


精确裁剪
--------
  在时间轴上滚动鼠标滚轮      以指针位置为中心缩放时间轴
  Shift + 鼠标滚轮            平移时间轴
  + / - / 0                   放大 / 缩小 / 显示完整时间轴
  ← / →                       1 秒（按住 Shift 为 5 秒）
  裁剪时的 ← / →              1 帧（按住 Shift 为 1 秒）
  起点、终点旁的 − 和 +       每次 1 帧（按住 Shift 为 1 秒），按住可连续调整
  I / O                       将当前位置设为起点 / 终点
  Home / End                  跳到片段的开头 / 结尾
  空格                        播放或暂停
  Esc                         退出裁剪；未在裁剪时返回首页

时间轴放大后，下方的滑块表示当前显示的范围，拖动可平移。

视频下方的「速度」按钮用于设置播放速度：0.5×、1×、2× 或 4×。裁剪时，「预览」
仅播放所选范围。勾选「导出后删除原视频」后，导出成功时原视频会被移至回收站。

片段以不重新编码的方式截取。在支持 MP4 编辑列表的播放器中（绝大多数播放器），
片段从所选的那一帧开始；少数播放器会从前一个关键帧开始播放，最多提前 2 秒。


其他说明
--------
· 语言：通过窗口右上角的按钮切换（中文 / English）。
· 片段为 MP4 文件，保存在保存位置中；未另行指定时，为"视频"文件夹中的
  Replay Clipper 文件夹。标题栏的「打开文件夹」可打开该文件夹。
· 磁盘空间：回放缓存默认保存在本文件夹的 data\buffer 中，占用程序所在磁盘的
  空间；如需放到其他磁盘，请在「录制设置」中更改缓存位置。缓存所在磁盘的可用
  空间不足以存放回放缓存时，录制不会开始；该磁盘的可用空间不足 1 GB 时，录制会
  停止，不会将磁盘写满。此时首页显示「磁盘空间不足」：清理磁盘后选择「重试」，
  或在「录制设置」中缩短回放时长。
· 选择「停止」时，以及退出程序时（通过图标菜单中的「退出」、关闭窗口时选择
  退出，或升级时由安装程序关闭程序），回放缓存会被丢弃。Windows 关机、注销或
  程序异常退出后，缓存文件仍留在磁盘上，下一次开始录制时会进行清理（早于回放
  时长的部分会被删除）。
· 录制所选的显示器未连接时，首页显示「所选显示器未连接」，此时无法录到新的画面，
  已录制的画面仍可保存。请重新连接该显示器，或在「录制设置」中选择其他显示器。
· 程序自身的数据（设置、日志、界面缓存，以及未另选缓存位置时的回放缓存）保存在
  本文件夹的 data 文件夹中。
  本文件夹不可写时（例如位于 Program Files 下），改用 %LOCALAPPDATA%\ReplayClipper。
· 移动或重命名本文件夹后，请从新位置启动一次程序。如果使用了
  「开机时启动并在后台录制」，请在「录制设置」中重新打开该选项。
· 分享给他人时，请提供安装程序（ReplayClipper-Setup-x.y.z.exe）。
  如果直接分享本文件夹，请先退出程序并删除 data 文件夹。其中是个人设置，程序会
  自动重建。
· 程序会在「设置 → 应用 → 已安装的应用」中为当前用户登记，无需管理员权限。


从 1.0 版升级
-------------
1.0 版通过 OBS Studio 录制，2.0 版不再使用 OBS。

· 运行 2.0 版的安装程序即可升级，安装位置默认为现有的安装文件夹。已保存的片段
  会保留，程序继续使用原来的保存文件夹。如果以前的片段没有列出，请在「录制设置」
  的保存位置中填写这些片段所在的文件夹。
· 需要设置一次录制，见上文"首次使用"一节。
· 保存时长和快捷键改在程序中设置（首页的「编辑」）。1.0 版的自定义时长会保留
  为第五个方块；在 OBS 中修改过的时长和快捷键不会沿用。
· 无需再为 Replay Clipper 运行 OBS 或它的回放缓存。1.0 版添加到 OBS 中的脚本，
  会在下一次启动 Replay Clipper 且 OBS 未运行时自动移除。
· 1.0 版在 OBS 中创建的"Replay Clipper"配置文件和场景集合会保留。可在 OBS 中
  自行删除，卸载程序也会询问是否删除。


卸载
----
在「已安装的应用」中卸载，或运行本文件夹中的 Uninstall.exe。卸载程序会关闭正在
运行的程序并停止录制，然后删除桌面快捷方式、开机启动项、程序文件、设置和回放
缓存（包括存放在其他位置的回放缓存）。已保存的片段不受影响；本文件夹中不属于
本程序的文件会保留。

如果本机使用过 1.0 版，卸载程序还会移除它留在 OBS 中的脚本，并询问是否一并删除
OBS 中的"Replay Clipper"配置文件和场景集合。OBS 及其其他设置不受影响。


文件夹内容
----------
  ReplayClipper.exe     程序
  Uninstall.exe         卸载程序
  Microsoft.Web.WebView2.*.dll、WebView2Loader.dll
                        显示窗口所需的 Microsoft WebView2 组件；
                        缺少时程序改用 Microsoft Edge 窗口打开，该窗口中
                        没有「浏览…」按钮，关闭窗口时也无法询问如何处理
  ui\                   界面
  ffmpeg\               视频处理（读取时长、生成缩略图、拼接和裁剪片段）
  engine\               录制组件：辅助程序 ReplayClipperEngine.exe（位于
                        engine\bin\64bit）、它使用的 OBS Studio 核心库，
                        以及相关的许可和声明文件（engine\licenses）
  src\                  程序的源代码；其中 src\engine 为录制组件辅助程序的
                        源代码
  build.cmd             编译脚本：根据 src\ 重新生成 ReplayClipper.exe、
                        Uninstall.exe 和 ReplayClipperEngine.exe
  data\                 首次运行后生成：设置、日志、界面缓存，以及默认
                        情况下的回放缓存（data\buffer）


第三方组件
----------
engine\ 中的录制组件基于 OBS Studio 33.0.1 的核心（libobs 及插件，未作修改；
https://obsproject.com）构建，后者按 GNU 通用公共许可证（GPL）第 2 版或更高
版本许可；其中还包含随 OBS Studio 一同发布的库，包括 FFmpeg 和 x264。这些
FFmpeg 库是按 GPL 第 3 版或更高版本许可的构建，因此所分发的 engine 文件夹
适用 GPLv3。加载这些库的辅助程序 ReplayClipperEngine.exe 是为 Replay Clipper
编写的，其自身的源代码位于 src\engine，按 GPL 第 2 版或更高版本许可。

engine\licenses 中包含：
  GPL-2.0.txt、GPL-3.0.txt   许可全文
  THIRD-PARTY-NOTICES.txt    所含的每个二进制文件及其版本、许可、来源和
                             上游源代码的位置
  FILES.sha256.txt           所含的 OBS Studio 文件和库文件的 SHA-256 校验值

ffmpeg\ffmpeg.exe 为 FFmpeg 项目（https://ffmpeg.org）的 9.0.2 版，只编译了
Replay Clipper 用到的部分，按 GNU 宽通用公共许可证（LGPL）第 2.1 版或更高版本
许可。许可全文见 ffmpeg\LICENSE.txt，源代码和编译脚本见 ffmpeg\README.txt。

三个 WebView2 文件来自 Microsoft 的 Microsoft.Web.WebView2 NuGet 包
（版本 1.0.2903.40），带有 Microsoft 的数字签名。窗口实际使用系统中已安装的
WebView2 运行时（Windows 11 自带，Windows 10 通常已随 Edge 安装）。


源代码
------
程序的源代码位于 src\，录制组件辅助程序的源代码位于 src\engine，两者均可用
build.cmd 重新编译。包括安装程序在内的完整项目发布在
https://github.com/Lunafreya123/ReplayClipper 。engine\ 中各组件的上游源代码，
可从 engine\licenses\THIRD-PARTY-NOTICES.txt 中为其列出的位置获取；
ffmpeg\ffmpeg.exe 的源代码见上文"第三方组件"一节。如果其中某个位置已无法访问，
可按 THIRD-PARTY-NOTICES.txt 中的说明索取相应的源代码。
